# Little Steps

An interactive visual learning application designed to help children with disabilities and children who benefit from step-by-step visual guidance learn everyday activities.

## Activities
- Washing Hands
- Brushing Teeth
- Tying Shoes

## Features
- Step-by-step visual instructions
- Audio guidance
- Previous and Next navigation
- Progress tracking
- Accessibility options

## Technologies
- Python
- Google Colab
- SQLite
- Interactive Widgets
- Text-to-Speech

## Machine Learning
Includes an experimental activity-recognition component using a public Activities of Daily Living dataset.
